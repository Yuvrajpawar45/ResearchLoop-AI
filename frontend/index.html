What it does

One question, four passes, one visible loop.

Most AI tools answer from memory. ResearchLoop actively searches the live web and GitHub in parallel, scores what it finds, self-corrects if evidence is thin, and synthesizes it into a structured, cited report.

Query decomposition

Your question is broken into 4 focused sub-questions — definition, comparison, use cases, and limitations — before any search begins.

Live web + GitHub search, in parallel

Tavily MCP searches the live web, GitHub MCP searches repositories — all 4 sub-questions run concurrently via LangGraph's Send() API, not one at a time.

Batched LLM scoring + dedup

Every sub-question's results are scored in one batched LLM call, then deduplicated by URL — only sources that clear the bar reach the Writer.

Self-correction loop

If too few sources clear the relevance bar, the graph loops back and retries once with a broader query — instead of writing a thin report anyway.

Cited report synthesis

The Writer node turns surviving sources into a structured markdown report with inline citations and a full sources list mapping each one back to its URL.

Groq inference, rate-limit aware

Planner, scorer, and Writer run on Groq's llama-3.3-70b-versatile, with automatic fallback to llama-3.1-8b-instant and graceful degradation if both are saturated.

How it works

Five nodes. One self-correcting loop.

Planner

decompose_query

Calls Groq with a structured prompt to split your query into 4 sub-questions covering different angles.

Research (× parallel)

research_one, fanned out via Send()

All sub-questions run concurrently, not sequentially: Tavily MCP + GitHub MCP search, then one batched LLM call scores each sub-question's results.

Aggregate

dedupe, rank, decide

Merges every parallel branch's results, filters by relevance, dedupes by URL — then decides whether evidence is strong enough to write, or too thin.

Broaden (conditional)

self-correction retry

Fires only if aggregate finds too few relevant sources: re-queries once with the original, broader question instead of the narrow sub-questions.

Writer

synthesize_report

Takes the final ranked source list and writes a structured markdown report with numbered citations.
